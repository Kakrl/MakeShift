Algorithm Idea (Shadow)
----
Given a fingertip point f(x) and a small constant c=4, constant d=4, constant e=4.
experiement with different constants, especially d
1. Get the point a few pixels above a(x) -> f(x) + c
2. get the edge of the finger to the right r(x) and left l(x) of the point a(x)
3. get the edge of the fingertip by going along the fingertip edge below those points and connecting together.
4. at each edge, check if it is connected to a shadow
5. if (4) is connected to a shadow, run a biased cluster means to see how far the shadow extends down making sure it is within a limit, d
6. run cluster mean that will try to go upwards or sideways, ensuring that the cluster extends past a(x) + e
7. if (5) fails, conclude not a press
8. if (6) fails, go onto next edge point
9. if at least one point passes, conclude a press


Algorithm in the live pipeline:

All/Light Shadow Test Algorithm
1. Check bottom of the finger tip and ensure there is some strip of the edge of the fingertip of x length with no shadow touching it
2. on either side of this strip should be some shadow joining into a large blob of shadow
