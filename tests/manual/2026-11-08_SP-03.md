## Preconditions

- Start with low device volume, then set a comfortable level using Loud A4.
- Select Enable audio and wait for the enabled status.

## Test Data

A0–C8 at the same velocity in the sweep, A4 soft and loud, individual notes
held for one second and the ten-note mixed-register chord. The current root
changes occur at MIDI 31, 38, 41, 44, 47, 50, 53, 56, 59, 62, 65, 68, 71,
74, 77, 80, 83 and 91. Compare each with its immediate lower neighbor.
