## Preconditions

Apply pedal and meter database migrations before shared round trips. Record
actual hardware/software versions and exported MIDI evidence. Calibrate and
enable live audio, then perform the full count-in before fresh presses. Use the
same piano instrument on MIDI channels 1–9 and 11–16 with CC64/66/67/120 support.

## Test Data

C4 repetitions and C4/E4/G4 chords at 120 BPM; sustain/sostenuto/soft individually
and combined. Include physical releases before pedal release and fresh repeated
pitches after sostenuto capture. Preserve the take JSON and exported MIDI.
